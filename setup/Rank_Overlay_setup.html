Use it in OBS

1. Click Download my overlay.html and save it somewhere permanent.
2. In OBS, add a Browser source and tick Local file.
3. Pick your downloaded overlay.html.
4. Set width 420 and height 170.
5. Done. It refreshes by itself. If you change settings, download a new file.
Your downloaded overlay.html contains your API key. Don't share that file or show it on stream. If you want to share with friends, share this setup page instead; it has no key in it.
